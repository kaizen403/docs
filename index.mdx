title: "OpenLinear"
description: "AI project management that actually writes the code. Drag tasks on a kanban board, click execute, get a pull request."
---

OpenLinear is a project management tool that uses AI agents to execute tasks. Create a task describing what you want built, click Execute, and OpenLinear runs an OpenCode agent that clones your repository, writes the code, and opens a pull request.

## What OpenLinear does

<CardGroup cols={2}>
  <Card title="Task Execution" icon="play" href="/features/task-execution">
    Run any task through an AI agent. OpenLinear clones your repo, creates a branch, and opens a PR.
  </Card>
  <Card title="Batch Execution" icon="layer-group" href="/features/batch-execution">
    Run multiple tasks in parallel or queue mode with conflict resolution.
  </Card>
  <Card title="Brainstorm" icon="brain" href="/features/brainstorm">
    Generate a task list from a natural language goal using AI.
  </Card>
  <Card title="MCP Integration" icon="plug" href="/integrations/mcp">
    Connect AI agents directly to OpenLinear via the MCP server to create projects and issues programmatically.
  </Card>
</CardGroup>
